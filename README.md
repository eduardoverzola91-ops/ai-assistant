Status
This project is in an early, pre-release stage. It is a solo effort, and the code is not yet runnable on a local machine. This repository exists to document the idea, the design and the roadmap in public while the first usable version is being built.
Nothing here is ready for production use yet.
Why this project exists
Investment advisory teams spend a lot of time on repetitive, structured work: preparing for client meetings, organizing information, and following up. Most of the tooling for this is closed, expensive or tied to a single firm, which makes it hard for smaller teams to adopt or adapt.
This project aims to provide an open, documented and reusable approach that any advisory team can study, adapt and improve.
Goals
Build a usable, well-tested v1 based on real advisory workflows.
Keep the design simple and easy to adapt to different teams and processes.
Publish clear documentation and adaptation guides so other teams can reuse the project.
Document how AI assistance was used during development, including what worked and what didn't.

Data and privacy
This repository does not contain and will never contain real client data, credentials, API keys or proprietary material from any employer. Examples and fixtures use fictional, anonymized data only.
